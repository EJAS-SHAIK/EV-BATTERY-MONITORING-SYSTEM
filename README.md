# EV Battery Monitoring System

## Project Overview
An IoT-based system for monitoring important electric vehicle battery parameters such as voltage, current, temperature, and battery status.

## Problem Statement
EV batteries need continuous monitoring to detect abnormal voltage, current, and temperature conditions. Manual monitoring can be difficult and may not provide early warnings.

## Solution
This project uses a microcontroller and sensors to continuously monitor battery parameters and provide real-time information about the battery condition.

## Technologies Used
- ESP32
- Embedded C
- Arduino IDE
- Voltage Sensor
- Current Sensor
- Temperature Sensor
- IoT

## Key Features
- Real-time battery voltage monitoring
- Current monitoring
- Temperature monitoring
- Battery status monitoring
- Detection of abnormal conditions
- IoT-based monitoring

## Working
1. Sensors measure battery parameters.
2. ESP32 collects the sensor readings.
3. The readings are processed by the program.
4. Battery status is monitored continuously.
5. Abnormal conditions can be detected and indicated.
